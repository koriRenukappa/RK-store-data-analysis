# RK-store-data-analysis (Interactive Dashboard Creation using MS Excel)
## Project Objective
The RK Store wants to create an annual sales report for 2022. So that, the owner of the RK Store can understand their customers & grow more sales in 2023 & 2024, 2025.

## Dataset used
- <a href="https://github.com/koriRenukappa/RK-store-data-analysis/blob/a6bf5e0e5cfed00350686d6a20a5093dfdf48030/RK%20Store%20data%20analysis.xlsx">Dataset</a>

## Questions (KPIs)
- Compare the sales and orders using single chart.
- Who purchased more Men or Women?.
- Which month got the highest sales and orders?
- What are different order status in 2022?
- List top 10 states contributing the states.
- Relation between age and gender based on number of orders.
- Which channel is contributing maximum to the sales.
- Percentage of totla orders delivered.
- Heighest selling category? 

## Dashboard
- <a href="https://github.com/koriRenukappa/RK-store-data-analysis/blob/a6bf5e0e5cfed00350686d6a20a5093dfdf48030/dashboard%20pic.PNG">View Dashboard</a>

## Process
- Verify data for any missing values & anomalies, and sort out the same.
- Made sure data is consistent & clean with respect to data type, data format and values used.
- Created pivot tables according to the question asked.
- Merge all pivot tables into one dashboard & apply slicer to make dynamic.
